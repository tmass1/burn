The first public release. One menu-bar ring for every AI account — how much is left, how fast it's going, and when it runs out at this pace.

**Install:** open `Burn.dmg` and drag Burn to Applications, or `brew install --cask tmass1/tap/burn`. macOS 14+, Apple silicon and Intel, signed and notarized. Press ⌥Space.

**What's in it**

- Claude (as many accounts as you have), ChatGPT via Codex, Grok, Gemini, Cursor and Copilot, read from the sign-ins already on your Mac; sign in from the app for the rest.
- **Pace.** A tick on every bar for where even use would be; a rate from Burn's own history; a yellow reset — and a notification — when a window will run out before it resets.
- **Unusual usage.** A banner when a window burns at several times your typical busy hour, or a model does several times a typical day's API work (2×, 3× or 5×, your call).
- **Launchers.** A `claude-<account>` command per Claude account; hover a row for *Open Terminal with this account*.
- **Command line.** `burn`, `burn json`, and `burn statusline` for Claude Code's status line.
- **Vendor status.** Anthropic, OpenAI, Cursor and GitHub incidents shown on the rows they affect.
- **Plan value.** What last month would have cost at API list prices, from Claude Code's logs.
- 90 days of history, pinned rings for more than one account in the menu bar, quiet hours.

No account, no telemetry, no server. Burn was Headroom; the first launch moves settings and history across.
