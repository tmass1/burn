**Burn updates itself.** From this version on, new releases arrive in the app: Burn looks for one shortly after it opens and once a day, and offers it in a Software Update window — what's new, then Install and Relaunch, Remind Me Later or Skip This Version.

- **Check for Updates…** is in the menu-bar menu, and Settings → General → Updates has the switch to turn the daily look off, plus Check Now.
- When Burn starts in the background at login, a new version doesn't throw a window over your work: an **Update** pill appears in the panel's header and one banner says so.
- Every update is checked against Burn's own signing key before it installs, and it has to carry the same Developer ID as the copy you're running; an archive changed by even one byte is refused.
- Homebrew installs are marked as self-updating, so `brew upgrade` leaves them to the app.

Coming from 2.0.0? That version can't update itself, so this one time open the new `Burn.dmg` or run `brew upgrade --cask burn`; every release after this arrives on its own.
