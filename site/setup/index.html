Setup guide

If you already use Claude Code, Codex or Cursor on this Mac, Burn works the moment it opens. Everything after the first step is optional.

Install it on your Mac

  1. Download Burn. It needs macOS 14 or later, on Apple silicon or Intel.
  2. Open the disk image and drag Burn to Applications.
  3. Open it, then press ⌥Space.

Or install it with Homebrew: brew install --cask tmass1/tap/burn. Either way, Burn updates itself from then on.

The first run

Burn looks for sign-ins already on your Mac and shows a row for each account it finds. macOS asks whether Burn may send notifications, which it uses to warn you before a plan runs out.

The panel opens over whatever you’re doing. Press ⌥Space again, press esc or click away to close it. You can change the shortcut in Settings, under General.

Add your accounts

If an account is missing, open Settings with the gear in the panel and choose Accounts.

Claude
The account Claude Code is signed in to appears by itself. For another, choose Add Account…, then Claude…, and sign in when your browser opens. Add as many as you have.
ChatGPT
Sign in to the ChatGPT app, or run codex login if you only have the Codex CLI. One account for now.
Grok
Choose Add Account…, then Grok…, and sign in when your browser opens. One account for now.
Gemini
Choose Add Account…, then Gemini…, and pick an account in your browser. You need Google’s Antigravity app installed. If you’re signed in there, Burn can use that instead.
Cursor
Sign in to the Cursor app.
Copilot
Any GitHub sign-in on your Mac works. If you have none, run gh auth login.

If a browser signs in to the wrong account, use Copy sign-in link and paste it into a private window.

Read the panel

Each bar is one window of a plan, such as the five-hour session or the week. The solid part is what you’ve used, and the hatched part is where your current pace puts you by the reset. Green is under 60%, yellow is up to 85%, and red is above that.

Right-click the ring in the menu bar to refresh, open Settings or turn on Launch at Login. To keep a second account beside it, use Also pin in Settings, under Appearance.

Choose your warnings

In Settings, under General, you can set how full a window gets before Burn says so, whether it tells you about resets and unusual days, and the hours it should stay quiet.

Commands and the status line

Also under General, Install adds the burn command, which prints what the panel knows, and Add puts the current account in Claude Code’s status line. Your own status line keeps running first.

With more than one Claude account, Accounts can install a command for each, so switching accounts is a different command instead of a different sign-in. If your shell can’t find them, add ~/.local/bin to your PATH.

Updates

Burn checks for a new version shortly after it opens and once a day, and asks before installing one. To check right away, choose Check Now in Settings, under General. You can turn the daily check off in the same place.
